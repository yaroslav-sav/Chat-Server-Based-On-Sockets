# Chat-Server-Based-On-Sockets

## Формат заголовка

Заголовок фиксированный — 8 байт.

COMMAND + LENGTH + DATA


COMMAND - 4 байта, существует 4 типа команд: 

JOIN - Регистрирует клиента под указанным именем

TEXT - Рассылает сообщение всем остальным подключённым клиентам (broadcast) с указанием, от кого оно

LIST - Отправляет клиенту список всех подключённых пользователей

QUIT - Корректно завершает соединение с этим клиентом


LENGTH - 4 байта, длина DATA в байтах


DATA является передаваемой информацией, длина не фиксирована
